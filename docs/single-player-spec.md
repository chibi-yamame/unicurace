# シングルプレイモード仕様書

## 1. 概要
シード値から生成した 5 つのステージを連続でクリアし、その総タイム（経過時間＋ペナルティ）を競うモード。
同じシード値を入力すれば同じ 5 ステージが生成されるため、友人とシードを共有して対戦できる。

実装: `index.html`（HTML / CSS）、`src/ui/app.js`（画面制御）、`src/game/`（ゲーム進行）。設定値は `src/config.js` の `CONFIG`

## 2. ゲーム定数
| 項目 | 値 | `CONFIG` キー |
| --- | --- | --- |
| ステージサイズ | 7 x 7 (固定) ※当初案は 6 x 6 | `gridSize` |
| 連続ステージ数 | 5 ステージ (固定) | `stageTotal` |
| ブロック率 | 0.15 ～ 0.35 (固定) | `blockRatioMin` / `blockRatioMax` |
| ストーン最大移動距離（生成用） | `gridSize - 1` (= 6) | — |
| ペナルティ | 3 秒 / 回 ※当初案は 1 秒 | `penaltyTime` (ms) |
| ストーン移動速度 | 0.045 秒 / マス ※当初は 0.06 | `moveSpeed` |
| スワイプ判定閾値 | 30 px | `swipeThreshold` |
| キャンバス最大サイズ | 400 px（画面幅の 90% を上限） | `canvasSize` |
| タイマー精度 | 1/100 秒 (0.01s) | — |

## 3. 画面遷移と詳細

```
タイトル → ステージ生成 → カウントダウン → ゲーム → 結果
   ↑                ↑                       │ ギブアップ   │ もう一度 / タイトルへ
   └────────────────┴───────────────────────┴──────────────┘
```

### 3.0 デザイン
- 配色は「夜のレース」: 藍の地（`#15123A`）に、石・タイマー・主ボタンの琥珀（`#FFB627`）と、塗り跡の水色（`#35C6DA`）の 2 色。ペナルティは赤（`#FF6B6B`）。CSS 変数として `index.html` の `:root` に定義（盤面の色は `src/view/renderer.js` の `THEME`）。
- 書体: 本文 Zen Kaku Gothic New、ロゴ Barlow Condensed、見出し Dela Gothic One、タイマー等の数字 DotGothic16（いずれも Google Fonts）。
- デザイン案（3 方向と採用案）はデザインキャンバスにまとめている。タイトル画面は案 A の配置を案 C の配色で、ゲーム画面は案 C を採用。

### 3.1 タイトル画面 (Title Screen)
- **表示要素**:
  - 小見出し「ONE-STROKE SLIDE PUZZLE」、ロゴ「UNICURACE」、サブタイトル「ユニキュレイス ― 一筆書き塗りつぶしパズル」
  - 塗り跡・石・未塗りマス・ブロックを横一列に並べた装飾
  - **シード入力欄**（ラベル「シード 同じ番号なら友だちと同じ 5 ステージ」、空欄時の表示「空欄でおまかせ」）: 0〜999999 の数字。数字以外（貼り付けを含む）は取り除かれ、6桁を超える分は切り捨て。
  - **ランダムボタン**: `Math.random()` で 0〜999999 を生成し、6桁ゼロ埋めで入力欄にセット。
  - 「ゲーム開始」ボタン
- **アクション**:
  - 「ゲーム開始」押下で**ステージ生成画面**へ遷移。
  - 入力が空の場合は `Date.now() % 1000000`（現在時刻ベースの6桁）をシードとする。

### 3.2 ステージ生成画面 (Generation Screen)
- **表示要素**:
  - メッセージ（構築中：「ステージ構築中...」、完了後：「ステージ構築完了！」）
  - 進行状況（例: `2 / 5 完了`）
  - **使用シード値表示**: `シード: 012345` のように6桁ゼロ埋めで表示。
  - 「スタート」ボタン (生成完了まで非活性、完了後に活性化)
- **内部処理**:
  - シード値で `SeededRandom` を1つ生成し、同じ乱数列から順に 5 ステージを `generateStageViaSimulationWithRetry` で生成。
  - ブロック率が範囲外の場合は最大 `N * 10` 回まで再生成し、範囲内のもの（なければ最も近いもの）を採用。
  - クリア可能性は生成側で保証している。生成時にストーンを実際に動かした経路がそのまま解になるため、別途 `findSolutionPath` を実行する必要はない。
    - `moveRangeMax` の値に関わらず保証される。詳細は `docs/algorithm-poc3.md`。
    - 全 233280 通りのシードで、生成経路をゲームと同じ移動ルールで再生し、5 ステージすべてクリアできることを確認済み。
  - 演出のため 1 ステージごとに 100ms 待機。
- **アクション**:
  - 「スタート」ボタン押下でペナルティ・統計をリセットし、**カウントダウン画面**へ遷移。

### 3.3 開始カウントダウン画面 (Countdown Screen)
- **表示要素**:
  - 画面中央に大きく「3」「2」「1」「GO!」と表示。
- **内部処理**:
  - 1秒ごとに表示を切り替え（3 → 2 → 1 → GO!）。
- **アクション**:
  - 「GO!」表示から 1 秒後（開始から約 4 秒後）に**ゲーム画面**へ遷移し、計測を開始。

### 3.4 ゲーム画面 (Game Screen)
- **表示要素**:
  - **システム操作エリア（上部）**: 「ギブアップ」ボタン、デバッグ用「Next(Debug)」ボタン。
  - 現在のステージ番号 (例: `LAP 1 / 5`)
  - **タイマーパネル**:
    - リアルタイムタイマー (`MM:SS.cc`、電光表示風)。**表示値はペナルティ加算済み**。
    - **累積ペナルティ表示**: ペナルティがある場合のみ、`+3.00s` を赤いバッジで表示。
    - **塗りの進み具合**: ゲージと `塗ったマス数/塗るべきマス数`（例: `15/35`、スタート地点を含む）。移動中は通過したマスも含めて更新。
  - パズルエリア (Canvas)。ゲーム画面の残り領域に収まる正方形（最大 400px）で、高解像度画面ではその解像度で描画。
    - 未塗りマス: 藍、塗りつぶし済み: 光る水色、ブロック: 盤面と同色の窪みに縁取り、ストーン: 光る琥珀の玉
  - **リセットボタン（下部）**: ステージを初期状態に戻す（ペナルティ発生）。ボタン内にペナルティ秒数（`+3秒`）を表示。
- **操作**:
  - キャンバス上でタッチ開始（またはマウス押下）し、離した位置との差が 30px を超えた場合、差の大きい軸の方向へ移動。
  - PC では矢印キーでも移動できる（キーを押しっぱなしにしたときのリピートは無視）。
  - ストーンは壁・ブロック・塗りつぶし済みマスにぶつかるまで滑り、通過マスをアニメーション中にリアルタイムで塗る。
  - 移動アニメーション中の入力・リセットは無視される。
- **内部処理**:
  - 全マス塗りつぶしでクリア判定。200ms の余韻の後、次のステージを表示。余韻の間は移動・リセットを受け付けない。
  - 5ステージ目はクリア判定の瞬間にタイマーを停止し、200ms の余韻の後に結果画面へ。
  - 通過したマスはフレームレートに関わらず必ず塗られる（フレームが飛んでも塗り漏れない）。
- **ペナルティとリセット（アラート非表示）**:
  - **自動リセット（行き止まり）**: 移動終了後、上下左右の隣接マスがすべて壁・ブロック・塗りつぶし済みで、かつ未クリアの場合、自動的にステージの最初に戻る。
  - **手動リセット**: リセットボタン押下でステージの最初に戻る。
  - いずれも総タイムに **3秒** が加算され、画面中央に `+3.00s` のポップアップが浮き上がって消える演出を表示。
- **アクション**:
  - **ギブアップ**: タイマーを止めてタイトル画面へ戻る。
  - **Next(Debug)**: 現在のステージを飛ばして次へ（最終ステージなら結果画面へ）。

### 3.5 結果画面 (Result Screen)
- **表示要素**:
  - 「FINISH!」のメッセージ
  - 最終確定タイム（経過時間 + ペナルティの合計。ゲーム画面のタイマー表示値）
  - **詳細統計**: `全5ステージ完了` / `行き止まり: n回 / リトライ: n回` / `(ペナルティ合計: x.x秒)`
  - 「もう一度」ボタン：**同じシード**でステージ生成からやり直し（同一の 5 ステージが再生成される）
  - 「タイトルへ」ボタン：タイトル画面へ戻る

## 4. 特記事項
- シードが同じなら 5 ステージの内容は常に同一。シード未入力時のみ現在時刻から自動決定する。
- 乱数生成器 (LCG) の法が 233280 のため、233280 違いのシード同士は同じステージ列になる。

## 5. 当初仕様と実装の差異
| 項目 | 当初仕様 | 現在の実装 |
| --- | --- | --- |
| ステージサイズ | 6 x 6 | 7 x 7 |
| ペナルティ | 1 秒 | 3 秒 |
| 解の存在確認 | `findSolutionPath` で確認し、解がなければリトライ | 生成アルゴリズム自体で保証（ソルバーによる事後検証は不要なため省略） |
| カウントダウン | 3秒経過後に開始 | 「GO!」表示の 1 秒後（約 4 秒後）に開始 |
