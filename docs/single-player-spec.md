# シングルプレイモード仕様書

## 1. 概要
シード値から生成した 5 つのステージを連続でクリアし、その総タイム（経過時間＋ペナルティ）を競うモード。
同じシード値を入力すれば同じ 5 ステージが生成されるため、友人とシードを共有して対戦できる。

実装: `index.html`（設定値は同ファイル内の `CONFIG`）

## 2. ゲーム定数
| 項目 | 値 | `CONFIG` キー |
| --- | --- | --- |
| ステージサイズ | 7 x 7 (固定) ※当初案は 6 x 6 | `gridSize` |
| 連続ステージ数 | 5 ステージ (固定) | `stageTotal` |
| ブロック率 | 0.15 ～ 0.35 (固定) | `blockRatioMin` / `blockRatioMax` |
| ストーン最大移動距離（生成用） | `gridSize - 1` (= 6) | — |
| ペナルティ | 3 秒 / 回 ※当初案は 1 秒 | `penaltyTime` (ms) |
| ストーン移動速度 | 0.06 秒 / マス | `moveSpeed` |
| スワイプ判定閾値 | 30 px | `swipeThreshold` |
| キャンバス最大サイズ | 400 px（画面幅の 90% を上限） | `canvasSize` |
| タイマー精度 | 1/100 秒 (0.01s) | — |

## 3. 画面遷移と詳細

```
タイトル → ステージ生成 → カウントダウン → ゲーム → 結果
   ↑                ↑                       │ ギブアップ   │ もう一度 / タイトルへ
   └────────────────┴───────────────────────┴──────────────┘
```

### 3.1 タイトル画面 (Title Screen)
- **表示要素**:
  - ゲームタイトル「Unicurace」、サブタイトル「一筆書き塗りつぶしパズル」
  - **シード入力欄**（ラベル「シード共有 (最大6桁)」）: 0〜999999 の数字。6桁を超える入力は切り捨て。
  - **ランダムボタン**: `Math.random()` で 0〜999999 を生成し、6桁ゼロ埋めで入力欄にセット。
  - 「ゲーム開始」ボタン
- **アクション**:
  - 「ゲーム開始」押下で**ステージ生成画面**へ遷移。
  - 入力が空の場合は `Date.now() % 1000000`（現在時刻ベースの6桁）をシードとする。

### 3.2 ステージ生成画面 (Generation Screen)
- **表示要素**:
  - メッセージ（構築中：「ステージ構築中...」、完了後：「ステージ構築完了！」）
  - 進行状況（例: `2 / 5 完了`）
  - **使用シード値表示**: `シード: 012345` のように6桁ゼロ埋めで表示。
  - 「開始」ボタン (生成完了まで非活性、完了後に活性化)
- **内部処理**:
  - シード値で `SeededRandom` を1つ生成し、同じ乱数列から順に 5 ステージを `generateStageViaSimulationWithRetry` で生成。
  - ブロック率が範囲外の場合は最大 `N * 10` 回まで再生成し、範囲内のもの（なければ最も近いもの）を採用。
  - 生成アルゴリズムの性質上、生成ステージは必ずクリア可能なため、`findSolutionPath` による検証は行っていない（`index.html` で import のみ）。
  - 演出のため 1 ステージごとに 100ms 待機。
- **アクション**:
  - 「開始」ボタン押下でペナルティ・統計をリセットし、**カウントダウン画面**へ遷移。

### 3.3 開始カウントダウン画面 (Countdown Screen)
- **表示要素**:
  - 画面中央に大きく「3」「2」「1」「GO!」と表示。
- **内部処理**:
  - 1秒ごとに表示を切り替え（3 → 2 → 1 → GO!）。
- **アクション**:
  - 「GO!」表示から 1 秒後（開始から約 4 秒後）に**ゲーム画面**へ遷移し、計測を開始。

### 3.4 ゲーム画面 (Game Screen)
- **表示要素**:
  - **システム操作エリア（上部）**: 「ギブアップ」ボタン、デバッグ用「Next(Debug)」ボタン。
  - 現在のステージ番号 (例: `STAGE 1 / 5`)
  - リアルタイムタイマー (`MM:SS.cc`)。**表示値はペナルティ加算済み**。
  - **累積ペナルティ表示**: ペナルティがある場合、`+3.00s Penalty` のように赤字で表示。
  - パズルエリア (Canvas)
    - ブロック: `#444`、空きマス: 白、塗りつぶし済み: `#b3d9ff`、ストーン: 赤 (`#ff4757`) の円
  - **リセットボタン（下部）**: ステージを初期状態に戻す（ペナルティ発生）。
- **操作**:
  - キャンバス上でタッチ開始（またはマウス押下）し、離した位置との差が 30px を超えた場合、差の大きい軸の方向へ移動。
  - ストーンは壁・ブロック・塗りつぶし済みマスにぶつかるまで滑り、通過マスをアニメーション中にリアルタイムで塗る。
  - 移動アニメーション中の入力・リセットは無視される。
- **内部処理**:
  - 全マス塗りつぶしでクリア判定。200ms の余韻の後、次のステージを表示。
  - 5ステージ目クリア後（同じく 200ms 後）にタイマーを停止し、結果画面へ。
- **ペナルティとリセット（アラート非表示）**:
  - **自動リセット（行き止まり）**: 移動終了後、上下左右の隣接マスがすべて壁・ブロック・塗りつぶし済みで、かつ未クリアの場合、自動的にステージの最初に戻る。
  - **手動リセット**: リセットボタン押下でステージの最初に戻る。
  - いずれも総タイムに **3秒** が加算され、画面中央に `+3.00s` のポップアップが浮き上がって消える演出を表示。
- **アクション**:
  - **ギブアップ**: タイマーを止めてタイトル画面へ戻る。
  - **Next(Debug)**: 現在のステージを飛ばして次へ（最終ステージなら結果画面へ）。

### 3.5 結果画面 (Result Screen)
- **表示要素**:
  - 「全ステージクリア！」のメッセージ
  - 最終確定タイム（経過時間 + ペナルティの合計。ゲーム画面のタイマー表示値）
  - **詳細統計**: `全5ステージ完了` / `行き止まり: n回 / リトライ: n回` / `(ペナルティ合計: x.x秒)`
  - 「もう一度」ボタン：**同じシード**でステージ生成からやり直し（同一の 5 ステージが再生成される）
  - 「タイトルへ」ボタン：タイトル画面へ戻る

## 4. 特記事項
- シードが同じなら 5 ステージの内容は常に同一。シード未入力時のみ現在時刻から自動決定する。
- 乱数生成器 (LCG) の法が 233280 のため、233280 違いのシード同士は同じステージ列になる。

## 5. 当初仕様と実装の差異（要検討）
| 項目 | 当初仕様 | 現在の実装 |
| --- | --- | --- |
| ステージサイズ | 6 x 6 | 7 x 7 |
| ペナルティ | 1 秒 | 3 秒 |
| 生成時の解の検証 | `findSolutionPath` で確認し、解がなければリトライ | 未実施（生成アルゴリズムで解の存在を保証） |
| カウントダウン | 3秒経過後に開始 | 「GO!」表示の 1 秒後（約 4 秒後）に開始 |
| タイマー停止 | 5ステージ目クリア判定の瞬間 | クリア判定から 200ms 後（余韻分がタイムに含まれる） |
