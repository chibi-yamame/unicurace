# シングルプレイモード仕様書

## 1. 概要
固定設定された 5 つのステージを連続でクリアし、その総タイムを競うモード。

## 2. ゲーム定数
- **ステージサイズ**: 6 x 6 (固定)
- **連続ステージ数**: 5 ステージ (固定)
- **ブロック率**: 0.15 ～ 0.35 (固定)
- **タイマー精度**: 1/100 秒 (0.01s)

## 3. 画面遷移と詳細

### 3.1 タイトル画面 (Title Screen)
- **表示要素**:
  - ゲームタイトル「Unicurace (ユニキュレイス)」
  - 「ゲーム開始」ボタン
- **アクション**:
  - ボタン押下後、**ステージ生成画面**へ遷移。

### 3.2 ステージ生成画面 (Generation Screen)
- **表示要素**:
  - 「ステージを構築中...」というメッセージ
  - 進行状況（例: 2/5 完了）などのインジケータ（任意）
  - 「開始」ボタン (生成完了まで非活性、完了後に活性化)
  
- **内部処理**:
  - 裏側で `SeededRandom` を使用し、5 つのステージを生成。
  - 各ステージに対し `findSolutionPath` を実行し、解が存在することを確認。
  - 解がない場合は自動的にリトライする。
- **アクション**:
  - 「開始」ボタン押下後、**カウントダウン画面**へ遷移。

### 3.3 開始カウントダウン画面 (Countdown Screen)
- **表示要素**:
  - 画面中央に大きく「3」「2」「1」「GO!」と表示。
- **内部処理**:
  - 1秒ごとにカウントを減らす。
- **アクション**:
  - 3秒経過後、自動的に**ゲーム画面**へ遷移し、計測を開始。

### 3.4 ゲーム画面 (Game Screen)
- **表示要素**:
  - 現在のステージ番号 (例: STAGE 1 / 5)
  - リアルタイムタイマー (00:00.00)
  - **累積ペナルティ表示**: リセット回数に応じた加算時間を赤字で表示。
  - パズルエリア (Canvas)
  - **リセットボタン**: ステージを初期状態に戻す。1秒のペナルティが発生。
  - **ギブアップボタン**: ゲームを中断してタイトル画面へ戻る。
- **内部処理**:
  - 1ステージクリア（全マス塗りつぶし）で即座に次のステージを表示。
  - 5ステージ目のクリア判定が出た瞬間にタイマーをストップ。
- **ペナルティとリセット（アラート非表示）**:
  - **自動リセット**: 移動終了後、どの方向にも移動できなくなった（詰み）場合、自動的にステージの最初に戻る。
  - **ペナルティ**: 自動リセット、または手動リセットボタン押下時に、総タイムに **1秒** が加算される。
- **アクション**:
  - 全クリア後、リザルト（結果表示）へ（※リザルト詳細は今後拡張）。

### 3.5 結果画面 (Result Screen)
- **表示要素**:
  - 「全ステージクリア！」のメッセージ
  - 最終確定タイム（経過時間 + ペナルティの合計）
  - **詳細統計**: 行き止まり回数、手動リトライ回数、ペナルティ合計秒数を表示。
  - 「もう一度」ボタン：ステージ生成からやり直し
  - 「タイトルへ」ボタン：タイトル画面へ戻る

## 4. 特記事項
- シングルプレイのシード値は、開始のたびに現在時刻などからランダムに生成するが、その回の5ステージ内では一貫性を保つ。
