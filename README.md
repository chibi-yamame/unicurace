# Unicurace (ユニキュレイス) - 一筆書き塗りつぶしパズル

直線的に滑るオブジェクトを操作して、グリッド上のすべてのマスを塗りつぶすパズルゲームのプロトタイプです。

## 概要

このプロジェクトは、スマホ向けWebアプリとしてのリリースを目指したパズルゲームのコアロジックおよびUIの検証用プロトタイプ（PoC）です。
プレイヤーは一方向を選択し、壁や障害物にぶつかるまで進むオブジェクトを操り、ステージ内のすべての「塗りつぶし可能マス」を通過することを目指します。

## 主な機能

- **確定的なステージ生成**: シード値ベースの乱数生成（LCG）により、同じシードからは常に同じステージを生成。
- **シミュレーションアルゴリズム**: 単なるランダム配置ではなく、実際に解く動きをシミュレートしながらブロックを配置し、パズルとしての面白さを担保。
- **自動ソルバー**: DFS（深さ優先探索）アルゴリズムを用いて、生成されたステージが本当にクリア可能かどうかを自動検証。
- **デバッグビジュアライザー**: ステージ生成時の想定解路をCanvas上に描画し、ロジックの妥当性を確認可能。

## 技術スタック

- **言語**: JavaScript (ES6+)
- **描画**: HTML5 Canvas API
- **UI**: HTML / CSS

## プロジェクト構造

- `src/core/`: ゲームの核心となるロジック。
  - `generator.js`: ステージ生成エンジン。
  - `solver.js`: パズルの解法を探索するDFSソルバー。
- `src/utils/`: 共通ユーティリティ。
  - `random.js`: シード付き乱数生成器。
- `tools/stage-inspector/`: 開発・デバッグ用ツール。
  - `index.html`: ステージ生成と解法の検証用ブラウザツール。
- `game-specification.md`: プロジェクトの全体仕様書。

## 始め方

ブラウザで `tools/stage-inspector/index.html` を開くことで、生成アルゴリズムの動作を確認できます。

1. リポジトリをクローンまたはダウンロード。
2. ブラウザ（Chrome/Edge等）で `poc4.html` を開く。
3. 「グリッドサイズ」や「ブロック率」を調整し、「複数ステージ生成」をクリック。

## アルゴリズムのポイント

### ステージ生成
1. ランダムな地点からスタート。
2. 4方向のうち進める距離を計算。
3. 乱数に基づき「あえて途中で止まる」ようにブロックを配置。
4. 移動不可になるまで繰り返し、最後に通らなかったマスをすべてブロックで埋める。

### ソルバー
すべての塗りつぶし可能マスが埋まるまで、再帰的に移動パターンを探索します。PoC段階では、パフォーマンス維持のため比較的小さなグリッド（最大20x20程度）に最適化されています。
